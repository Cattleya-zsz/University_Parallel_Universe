# 大学平行时空 University Parallel Universe

> ⚠️ **项目状态**: 基础框架已完成，正在等待其他成员提供数据和功能模块。

## 项目介绍

面向高中生的专业一日模拟项目，通过"选择专业 → 模拟一天 → 做出生活选择 → 生成校园路线和个人画像"的方式，让高中生直观感受不同专业的大学生活节奏。

## 核心流程

```
进入 Web App
→ 选择一个专业
→ 进入该专业的一日日程模拟
→ 在五个时间段中做选择
→ 每个选择绑定一个事件和校园地点
→ 根据选择更新多维度分数
→ 在可视化界面形成一天的校园路线
→ 最终总结专业、路线和个人画像
```

## 快速开始

```bash
cd web
npm install
npm run dev
```

然后访问 http://localhost:5173/

## 分工说明

### 角色 A（当前仓库） - 前端主流程

**负责范围**：
- ✅ 能进入首页并选择专业
- ✅ 能进入五阶段模拟
- ✅ 每次点击选项都能进入下一步
- ✅ 模拟结束后能进入结果页
- ✅ 结果页能正确读取分数和画像
- ✅ 地图组件可以被挂载
- ✅ 课程问答区域可以被挂载

**不负责**：
- ❌ 设计评分逻辑
- ❌ 设计课程问答后端
- ❌ 实现地图路线逻辑
- ❌ 提供专业数据、日程模板、评分函数、画像生成函数

### 角色 B - 数据与逻辑

**需要提供**：
- `majors.json` - 专业数据
- `experienceTemplates.json` - 五阶段日程模板
- `score.js` - 评分计算函数
- `profile.js` - 画像生成函数

### 角色 C - 可视化组件

**需要提供**：
- `locations.json` - 校园地点数据
- `CampusMap.jsx` - 校园地图组件
- `CourseChat.jsx` - 课程问答组件
