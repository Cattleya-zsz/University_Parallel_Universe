# 角色 C 开发指导

你负责本项目的地图模块、数据清洗和展示材料。

项目名称：`University Parallel Universe`

你的模块不是附属功能，而是这个项目最重要的前端展示亮点之一。

项目希望通过：

```text
人工标注的等距校园插画地图
+ 用户事件选择
+ 发光路线生成
```

让“专业的一天”变得可视化、可感知。

## 1. 你的目标

你要把抽象的事件序列，变成一条清晰、好看的校园路线。

同时，你还负责：

- 清洗活动样本
- 统一地点类型
- 准备展示材料

## 2. 你的主要任务

- 设计校园简化地图方案
- 整理地点坐标数据
- 完成 `CampusMap.jsx`
- 统一地图点位命名
- 清洗活动样本中的地点类型和活动类型
- 准备 README、PPT、展示讲稿

## 3. 你负责的文件范围

重点开发：

```text
web/
├─ src/
│  ├─ components/
│  │  └─ CampusMap.jsx
│  ├─ data/
│  │  └─ locations.json
│  └─ utils/
│     └─ route.js
```

你还会影响：

- `experienceTemplates.json` 中的 `locationId`
- 结果页中的地图展示区域
- 展示材料中的地图说明

## 4. 地图模块目标

当前项目不做真实地图导航，不接复杂地图 API。

你要做的是：

- 使用一张人工标注的等距校园插画底图作为底图
- 在底图上按相对坐标放置地点
- 根据用户选择动态生成发光连线
- 展示路线顺序
- 让地图成为结果页视觉亮点

## 5. 推荐实现方式

建议方案：

```text
校园底图图片
+ 绝对定位点位
+ SVG 或 CSS 连线
+ 当前节点高亮
+ 路线编号
```

如果时间够，可以做轻微立体化：

- 等距视角风格底图
- 轻微建筑阴影
- 发光路线
- 当前节点脉冲动画
- 轻手账式地点标签或信息贴纸

但不要做：

- 真实 3D 引擎
- 自动寻路
- 复杂地图拖拽缩放

## 6. locations.json 要求

每个地点至少有：

```json
{
  "id": "library",
  "name": "图书馆",
  "x": 62,
  "y": 35,
  "type": "study"
}
```

说明：

- `id` 必须稳定，供模板和路线引用
- `x/y` 使用百分比坐标
- `type` 用于决定颜色或图标风格

建议地点类型：

```text
study
life
sport
social
practice
medical
```

## 7. CampusMap 组件要求

输入：

```js
locations
route
```

输出：

- 可视化路线图

组件职责：

- 渲染校园底图
- 渲染地点点位
- 渲染路线连接线
- 给点位加顺序编号
- 高亮最终路线

不负责：

- 计算分数
- 生成画像
- 自己推断路线

## 8. 数据清洗任务

你还需要清洗当前活动样本。

重点清洗：

- 合并 `吃饭` 与 `午饭`
- 处理 `晨读` 是否单列或并入 `自习`
- 统一 `医院 / 门诊 / 教学医院`
- 统一 `体育馆 / 健身房`
- 处理 `未知` 和明显异常点位

目标：

- 给成员 B 一个更稳定的 `locationId` 和活动分类基础
- 给地图模块一个更少歧义的地点池

## 9. 与其他成员的协作边界

你服务成员 A：

- 提供 `CampusMap.jsx`
- 提供 `locations.json`
- 提供结果页可展示的路线样式

你协作成员 B：

- 统一 `locationId`
- 对齐活动类型与地点类型
- 让课程“上课事件”能正确落到地图地点

你不负责：

- 主前端页面逻辑
- 评分算法
- AI 后端接口

## 10. 你交付后的验收标准

你完成后，应该满足：

- 地图底图可以正常显示
- 点位坐标正确
- 路线能根据 `route` 动态变化
- 点位有顺序编号
- 结果页中地图清晰可读
- 地点命名和 `locationId` 统一
- 展示材料能清楚解释地图模块价值

## 11. 建议给 AI coding 工具的任务拆分

推荐顺序：

1. 设计 `locations.json`
2. 生成 `route.js`
3. 生成 `CampusMap.jsx`
4. 加点位样式和顺序编号
5. 加高亮和轻微动画
6. 调整底图与坐标映射

## 12. 可直接给 AI coding 工具的提示词

```text
你现在是这个项目的地图与展示模块开发者。
请实现一个 React 组件 CampusMap，用于展示大学校园简化地图上的动态路线。

要求：
1. 使用一张校园简化底图作为背景
2. 地点数据来自 locations.json，包含 id、name、x、y、type
3. 路线数据 route 是地点 id 数组或地点对象数组
4. 在地图上显示地点点位、顺序编号、连接线和当前路线高亮
5. 使用相对坐标，不使用真实地图 API
6. 不要实现自动寻路，不要引入复杂地图 SDK
7. 风格适合作为结果页亮点，可以有轻微动效，但不要影响稳定性
```
